# jlox

A complete tree-walking interpreter for **Lox**, a small dynamically typed,
object-oriented scripting language, written in Java. Implements the full
language from Part II of Robert Nystrom's
[*Crafting Interpreters*](https://craftinginterpreters.com/): lexing,
recursive-descent parsing, static variable resolution, closures, classes, and
inheritance.

```lox
class Doughnut {
  cook() {
    print "Fry until golden brown.";
  }
}

class BostonCream < Doughnut {
  init(filling) {
    this.filling = filling;
  }

  cook() {
    super.cook();
    print "Pipe full of " + this.filling + ".";
  }
}

BostonCream("custard").cook();
```

```
$ java -jar target/jlox.jar doughnut.lox
Fry until golden brown.
Pipe full of custard.
```

## Language features

- **Types:** numbers (double-precision), strings, booleans, `nil`
- **Expressions:** arithmetic, comparison, equality, string concatenation,
  logical `and`/`or` with short-circuiting, grouping
- **Variables** with lexical block scoping and shadowing
- **Control flow:** `if`/`else`, `while`, `for`
- **Functions:** first-class functions, recursion, closures, `return`
- **Classes:** fields, methods, initializers (`init`), `this`, bound methods
- **Inheritance:** single inheritance with `<` and `super` method calls
- **Native functions:** `clock()`
- **Error reporting:** syntax errors with line numbers and panic-mode recovery
  (multiple errors reported per run), static semantic errors, and runtime type
  errors

## Architecture

Source code flows through four stages:

```
source ──► Scanner ──► tokens ──► Parser ──► AST ──► Resolver ──► Interpreter
```

| Stage | File | What it does |
|---|---|---|
| Lexing | [`Scanner.java`](src/main/java/lox/Scanner.java) | Converts source text into tokens using maximal munch; recognizes keywords, literals, and comments |
| Parsing | [`Parser.java`](src/main/java/lox/Parser.java) | Recursive-descent parser producing an AST; one method per grammar rule, precedence encoded in the call chain; desugars `for` into `while` |
| AST | [`Expr.java`](src/main/java/lox/Expr.java), [`Stmt.java`](src/main/java/lox/Stmt.java) | Syntax tree node classes using the Visitor pattern; generated by [`GenerateAst.java`](src/main/java/tool/GenerateAst.java) |
| Resolution | [`Resolver.java`](src/main/java/lox/Resolver.java) | Static pass that binds every local variable reference to its declaring scope, fixing closure semantics and catching errors like `return` at top level or `this` outside a class |
| Evaluation | [`Interpreter.java`](src/main/java/lox/Interpreter.java) | Tree-walking evaluator over the AST, with a chain of [`Environment`](src/main/java/lox/Environment.java)s for scope |
| Runtime | [`LoxFunction`](src/main/java/lox/LoxFunction.java), [`LoxClass`](src/main/java/lox/LoxClass.java), [`LoxInstance`](src/main/java/lox/LoxInstance.java) | Runtime representations of functions (with captured closures), classes, and instances |

### Grammar

```
program        → declaration* EOF ;

declaration    → classDecl | funDecl | varDecl | statement ;
classDecl      → "class" IDENTIFIER ( "<" IDENTIFIER )? "{" function* "}" ;
funDecl        → "fun" function ;
varDecl        → "var" IDENTIFIER ( "=" expression )? ";" ;

statement      → exprStmt | forStmt | ifStmt | printStmt
               | returnStmt | whileStmt | block ;

expression     → assignment ;
assignment     → ( call "." )? IDENTIFIER "=" assignment | logic_or ;
logic_or       → logic_and ( "or" logic_and )* ;
logic_and      → equality ( "and" equality )* ;
equality       → comparison ( ( "!=" | "==" ) comparison )* ;
comparison     → term ( ( ">" | ">=" | "<" | "<=" ) term )* ;
term           → factor ( ( "-" | "+" ) factor )* ;
factor         → unary ( ( "/" | "*" ) unary )* ;
unary          → ( "!" | "-" ) unary | call ;
call           → primary ( "(" arguments? ")" | "." IDENTIFIER )* ;
primary        → "true" | "false" | "nil" | "this" | NUMBER | STRING
               | IDENTIFIER | "(" expression ")" | "super" "." IDENTIFIER ;
```

## Getting started

Requires **Java 23+** and **Maven 3.9+**.

```bash
# build, run the test suite, and produce target/jlox.jar
mvn package

# start the interactive REPL (Ctrl-D to exit)
java -jar target/jlox.jar

# run a script
java -jar target/jlox.jar examples/classes.lox
```

Or run straight from source without building a jar:

```bash
mvn compile exec:java                                       # REPL
mvn compile exec:java -Dexec.args="examples/fibonacci.lox"  # script
```

Exit codes follow the book's conventions: `65` for compile errors (syntax or
resolution) and `70` for runtime errors.

## Examples

The [`examples/`](examples) directory contains runnable programs covering each
feature area:

| File | Demonstrates |
|---|---|
| [`hello.lox`](examples/hello.lox) | printing, native functions |
| [`expressions.lox`](examples/expressions.lox) | operators, precedence, truthiness |
| [`control_flow.lox`](examples/control_flow.lox) | `if`/`else`, logical operators, `while`, `for` |
| [`fibonacci.lox`](examples/fibonacci.lox) | functions and recursion |
| [`closures.lox`](examples/closures.lox) | closures, higher-order functions |
| [`scope.lox`](examples/scope.lox) | static resolution and shadowing |
| [`classes.lox`](examples/classes.lox) | classes, initializers, inheritance, `super`, bound methods |

## Testing

```bash
mvn test
```

The JUnit suite in [`LoxTest.java`](src/test/java/lox/LoxTest.java) runs every
program in `examples/` and checks its output against the `// expect:` comments
in the source. It also covers scanning, operator precedence, and syntax,
resolution, and runtime error reporting.
